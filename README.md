# FitSync AI (Shyft)

> **Практична робота №2:** Бізнес-документ і архітектурна діаграма  
> **Референс:** `~/Projects/shyft` (FitSync AI)

FitSync AI — адаптивна фітнес-екосистема нового покоління з емпатичним цифровим коучем Nix, що допомагає новачкам подолати психологічний бар'єр «gymtimidation» за допомогою безпечної адаптації навантаження у реальному часі.
